# חמש דקות — אפליקציית חדשות אישית

תקציר יומי קצר של החדשות בישראל, בעברית, מותאם למובייל.
מושך מ-Ynet, N12 ועוד, מאחד ידיעות על אותו אירוע ממקורות שונים, מדרג לפי חשיבות,
ומגיש אותן בעיצוב מגזין. כל ידיעה מקשרת למקור המקורי — האפליקציה לא מעתיקה כתבות,
רק כותרת ותקציר.

## איך זה עובד

אין שרת שצריך להשאיר דולק. רובוט בענן מושך את הפידים כל חצי שעה, מריץ את כל
העיבוד, ושומר קובץ אחד — `feed.json`. האתר עצמו סטטי: הוא קורא את הקובץ ונטען מיידית.

```
GitHub Actions  ──כל 30 דק׳──▶  feed.json  ──▶  GitHub Pages  ──▶  הטלפון שלך
```

ההעדפות שלך — רשימת חסימה, משקלי נושאים, שעות תזכורת — נשמרות **בטלפון עצמו**,
לא בענן. הדירוג והסינון רצים בדפדפן, ולכן שינוי בהגדרות משפיע מיד.

## העלאה לאוויר (פעם אחת)

1. **פתח חשבון GitHub** ב-<https://github.com/signup> אם אין לך. חינם, דקה.

2. **צור מאגר חדש** ב-<https://github.com/new>. תן לו שם, למשל `news`.
   השאר אותו Public (זה מה שמאפשר Pages בחינם). אל תסמן שום תיבה נוספת.

3. **העלה את הקוד.** בטרמינל בתיקיית הפרויקט:

   ```bash
   git init -b main
   git add .
   git commit -m "גרסה ראשונה"
   git remote add origin https://github.com/USERNAME/news.git
   git push -u origin main
   ```

   החלף `USERNAME` בשם המשתמש שלך.

4. **הפעל את Pages.** במאגר: Settings ← Pages ← תחת Source בחר **GitHub Actions**.

5. **הרץ פעם ראשונה.** בלשונית Actions ← "עדכון חדשות ופרסום" ← Run workflow.
   אחרי כדקה האתר יהיה ב-`https://USERNAME.github.io/news/`.

מכאן זה מתעדכן לבד כל חצי שעה.

### התקנה בטלפון

פתח את הכתובת בטלפון. בכרום: תפריט ⋮ ← "הוספה למסך הבית".
באייפון בספארי: שיתוף ← "הוסף למסך הבית".
מכיוון שזה HTTPS אמיתי, ההתקנה והתזכורות עובדות כמו שצריך.

## עבודה מקומית

```bash
npm install
npm ci --prefix web
npm run feed      # מושך חדשות ויוצר את feed.json
npm run dev       # פותח את האתר על http://localhost:3000
```

`npm run feed` הוא מה שהרובוט מריץ בענן. אם דילגת עליו, האתר יציג הודעה שאין קובץ חדשות.

## מה יש באפליקציה

| לשונית | מה היא עושה |
|---|---|
| **תקציר** | הסיפורים החשובים של היום, ואחריהם "עדיין מתגלגל" |
| **הכול** | שאר הידיעות, עם סינון לפי נושא |
| **חידון** | 3 שאלות על חדשות היום, עם רצף ימים. דורש מפתח Gemini |
| **הגדרות** | כמה סיפורים בתקציר, תזכורות, משקלי נושאים, רשימת חסימה |

## סיפורים מתגלגלים

בסוף התקציר יש סעיף "עדיין מתגלגל": אירועים שלא קרו היום, אבל עדיין מסקרים אותם —
הדלפה שנחשפה לפני שבועיים, גל תקיפות שנמשך שמונה ימים. לכל אחד ציר זמן שמראה איך
הסיפור התפתח יום אחרי יום.

המקורות שלנו מספקים רק את היממה האחרונה, ולכן המבט לאחור נעשה מול חיפוש Google News
(חינם, בלי מפתח) לארבעה-עשר יום אחורה. אירוע נחשב מתגלגל אם הוא בן יומיים וחצי לפחות,
סוקר בשלושה ימים נפרדים או יותר, ויש עליו ארבע כתבות לפחות.

ציר הזמן מושך מכל העיתונות, לא רק מהמקורות שבהגדרות. כשיש כמה כתבות מאותו יום
האפליקציה מעדיפה גוף מוכר, אבל ביום שבו רק אתר קטן סיקר — הוא זה שיופיע.

## רשימת החסימה

בהגדרות, לא בקוד. שני סוגים:

- **שמות** — חוסמים רק תוכן שהאדם מפרסם בעצמו: טור דעה, ראיון, או ציטוט שלו בכותרת.
  דיווח עיתונאי על מה שהוא עושה ימשיך להופיע.
- **מילות מפתח** — חוסמות כל ידיעה שמכילה את המילה, בלי יוצא מן הכלל.

ברירת המחדל ריקה.

## סיכומי AI (אופציונלי, חינם)

בלי מפתח האפליקציה עובדת מלא — התקצירים מגיעים מהמקורות עצמם.
עם מפתח Gemini (שכבה חינמית) מתווספים "למה זה חשוב", "רקע" וחידון יומי.

1. קבל מפתח חינם ב-<https://aistudio.google.com/apikey>
2. **בענן:** במאגר ← Settings ← Secrets and variables ← Actions ← New repository secret,
   בשם `GEMINI_API_KEY`.
3. **מקומית:** העתק את `.env.example` ל-`.env` והכנס שם את המפתח.

**מפתחות API אף פעם לא נכנסים לקוד ולא ל-git.** `.env` מוחרג ב-`.gitignore`,
ו-Secret של GitHub אינו נחשף בלוגים.

## מקורות

מוגדרים ב-`config/sources.json`. כדי להוסיף מקור, הוסף שורה עם `url` של פיד RSS.
הפידים שנבדקו ועובדים: Ynet (4 ערוצים), N12 (3), הארץ, שיחה מקומית, שקוף,
Times of Israel. כלכליסט, גלובס וכאן חוסמים גישה ולכן אינם ברשימה.

**על טוויטר/X:** ה-API החינמי אינו מאפשר קריאת ציוצים, והדרגה הזולה ביותר שכן
עולה כמאתיים דולר לחודש. מופעי Nitter (המעקף החינמי) אינם פעילים עוד.
לכן אין X באפליקציה, ובמקומו נכנסו מקורות פרשנות עם RSS עובד.

## תזכורות

ברירת המחדל: 11:00 ו-16:30, ניתן לשנות בהגדרות.
ההתראה נשלחת כשהאפליקציה מותקנת ופתוחה ברקע. בלי שרת push אין דרך להבטיח
התראה כשהמכשיר סגור לגמרי — זה המחיר של פתרון חינמי לחלוטין.

## מבנה הפרויקט

```
config/sources.json    רשימת הפידים
pipeline/              קוד שרץ רק בענן:
  collect                משיכה ונירמול
  cluster                איחוד ידיעות על אותו אירוע
  noise                  סינון תוכן שיווקי ושאינו חדשות
  enrich                 Gemini (אופציונלי)
  lookback               מבט 14 יום אחורה לזיהוי סיפורים מתגלגלים
scripts/build-feed     נקודת הכניסה של הרובוט
web/src/shared/        קוד שרץ בשני המקומות: דירוג, בלוקליסט, סיווג נושאים
web/src/               React + Tailwind, RTL
web/public/feed.json   התוצר — מה שהאתר קורא
.github/workflows/     תזמון הרובוט והפרסום
```

## איך הדירוג עובד

ציון = סיקור (40%) + טריות (30%) + התאמה לנושאים שלך (30%), עם הטיה קלה למקורות
שמאל ועם הורדה לתוכן דעה. **סיקור** הוא כמה גופי חדשות שונים דיווחו על אותו אירוע —
האות החזק ביותר לחשיבות. את משקלי הנושאים אפשר לכוונן בהגדרות.
